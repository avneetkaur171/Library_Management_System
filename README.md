# Library_Management_System
Library Management System using C++

A console-based library system built with OOP concepts: abstract class,
inheritance, polymorphism, encapsulation, exception handling, file handling.

## Features
Book management, member management (Student/Faculty), issue/return,
fines (Rs. 5/day after 14 days), history, popular books, recommendations.

## How to compile and run
g++ -std=c++17 main.cpp -o library
./library

## Data files
books.txt, members.txt, transactions.txt are created in the folder where you run the program.
